# Liquid Portfolio — 架空の流動資産ポートフォリオゲーム

**開発候補／Microsoft Store販売HOLD。** 日々の買い・売り・現金保有・架空の借入・返済を、ひとつのダッシュボードから操作します。

- `index.html`: 新しい流動性の高い架空資産4種類の売買ゲーム。各商品はゲーム内で即時売却可能（外部の実市場とは関係ありません）。
- `legacy.html`: 以前の24四半期投資配分ゲーム。旧エンジン／`fictional-finance:save:v1`を残し、保存データを上書きしません。
- 新版保存キー: `liquid-portfolio:save:v2`。取引履歴から全資産・現金・借入・手数料を再計算し、不一致は読み込み拒否。リセット直前のデータは別枠に退避。
- 無制限の実資金・信用取引ではありません。架空の借入上限30,000ポイント、日次利息0.03%、手数料0.2%（最低1pt）、空売り不可。
- 新版は120営業日。架空価格を日次に更新し、現金・保有資産・負債・純資産・収益推移を表示します。実物の証券・API・アカウント・換金はなし。
